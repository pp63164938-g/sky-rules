# i18n 翻译规范

**核心原则**：**禁止自动生成翻译**，所有未由用户提供的翻译必须使用 `TODO翻译_` 前缀标记。

**适用场景**：新增翻译 key、替换硬编码文案、多语言文件扩展、长文案结构拆分。

**硬性红线**：禁止自行翻译用户未提供的语言；禁止在 i18n 中混入复杂 HTML 或样式；扩展前必须确认实际使用的语言入口文件。

## 禁止自动生成翻译

- 当用户未提供某语言的翻译时，**绝对禁止自行发散生成翻译**
- 应使用 `TODO翻译_` 前缀 + 已提供的原文作为占位符
- 示例：`"TODO翻译_綁定推薦人"` 而非自行翻译为 `"Bind Referrer"`
- 便于后续全局搜索 `TODO翻译_` 进行翻译补充

## 扩展 i18n key 时的规则

当需要添加新的翻译 key 时（如替换硬编码中文为 i18n）：

1. **中文文件**：正常添加中文内容
2. **英文文件**：**必须使用 `TODO翻译_中文原文` 作为占位符**
3. **完成后**：主动告知用户新增了哪些待翻译的 key

```javascript
// ❌ 禁止 - 自行生成英文翻译
codeSent: "Verification code sent";

// ✅ 正确 - 使用 TODO翻译_ 标记
codeSent: "TODO翻译_验证码已发送";
```

## 使用规则

1. **已有翻译**：项目中已存在的完全匹配的翻译可直接使用
2. **新增翻译**：仅有中文时，英文**必须**使用 `TODO翻译_中文原文` 占位
3. **用户提供**：用户明确提供的翻译内容可直接使用
4. **发现问题**：如用户提供的翻译有错误（如翻译错位），应先询问用户确认再修正

## 注释规范

- **各语言文件注释保持一致**：所有 i18n 文件（cn.js、en.js 等）的注释内容必须与中文文件保持一致
- **使用简体中文注释**：便于阅读和定位对应模块
- **示例**：`// 合同签署页面` 而非 `// Contract Sign Page`

# i18n 文件扩展规范（通用）

**核心原则**：扩展 i18n 翻译时，**必须先查看项目的 i18n 入口文件**（通常是 `src/i18n/langs/index.js` 或 `src/i18n/index.js`），确定当前实际使用的语言文件，只扩展被引用的文件。

**操作步骤**：

1. **先查看 i18n 入口**：确认哪些语言文件被实际引用
2. **只扩展被引用的文件**：避免修改未使用的语言文件
3. **记录发现**：如果发现有文件未被使用，应在对话中说明

**目的**：避免扩展未被使用的语言文件，减少无效工作和潜在错误。

## 禁止在 i18n 中编写 HTML 结构与样式

**核心原则**：禁止在 i18n 语言文件中混入复杂的 HTML 结构（如 `<div>`、`<p>`）或任何 CSS 样式（如 `style="..."`、`class="..."`）。

**目的**：保持 i18n 文件的纯粹性，确保结构与内容分离，降低后续翻译和维护的难度。

**操作要求**：

- **纯文本为主**：i18n 文件中尽量只保留纯文本，长文本与特殊结构建议通过数组或多个独立属性进行拆分。
- **允许的轻量标签**：仅在特殊需要时，允许在 i18n 中使用极少量的行内基础占位标签（如 `<strong>`、`<br/>`）。
- **样式分离**：需要特殊样式（如特定颜色高亮）的文本，必须将其拆分为独立的 i18n 变量，并交由 Vue 模板（如 `<span class="xxx">{{ $t('...') }}</span>`）来负责渲染样式。**绝对禁止**在 i18n 文件中硬编码 `style="..."` 或长篇大论的 DOM 结构。

**反面案例**：

```javascript
// ❌ 禁止 - 在 i18n 中硬编码样式和复杂 HTML 结构
contentHtml: '<div class="wc-rule"><span style="color: #E57200">$100,000</span></div>';
```

**正确做法**：

```javascript
// ✅ 正确 - i18n 仅保留纯文本
prefix: '瓜分',
amount: '$100,000',
suffix: '现金'
```

```vue
<!-- ✅ Vue 模板中处理结构与样式 -->
<div class="wc-rule">
    {{ $t('prefix') }}<span class="highlight-amount">{{ $t('amount') }}</span>{{ $t('suffix') }}
</div>
```
