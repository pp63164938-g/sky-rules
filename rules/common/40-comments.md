# 代码清理规范

修改代码时同步清理废弃资源：

1. **替换 i18n 翻译 key 时**：同时删除被替换的旧 key
2. **删除/修改组件引用时**：检查被引用的资源（翻译、图标、样式）是否还有其他地方使用，没有则删除
3. **修改完成后**：使用搜索工具确认旧代码/翻译确实无引用

**目的**：避免遗留无用代码和翻译，保持代码库整洁。

# 注释规范

**注释内容边界**：

- 代码注释只服务后续维护者理解业务含义、数据来源和分支原因，并且只描述当前代码需要长期维持的业务事实；禁止记录任务执行过程。
- 禁止将 AI 与用户的交流留痕写进业务代码，包括“用户已确认”“按本轮沟通”“参考本次截图”“查证后发现组件默认支持”“为了遵守规则”等过程性说明。
- 需求澄清、用户确认、方案取舍、组件 / Hook 默认能力查证和代码审查结论，应记录在对话、需求决策台账、方案文档或交付说明中。如果沟通结论形成代码无法自行表达、且需要长期维护的业务约束，必须改写成不包含沟通过程的业务事实后再添加注释。
- 如果组件类型、Prop、校验规则、变量命名或代码结构已经完整表达约束，禁止为了证明 AI 已理解、已查证或已执行而重复添加注释。
- 禁止写“禁止使用 xxx”“按规则 xxx”“避免违反 xxx”这类给 AI 自己看的规则执行说明。
- 禁止把本次排错、复盘、审查提醒、工具判断过程写成代码注释；这些内容应放在对话回复、方案文档或规则复盘中。
- 禁止用注释替代最终回复中的发散点、待确认项或兜底说明；代码注释和用户交付说明是两件事。
- 禁止把本次改动交代、字段收口说明、方案取舍过程写进代码注释。例如“统一使用同一接口字段”“已确认业务类型都走该字段”“兼容新旧字段后收口”“按审查意见调整”。这些是给用户的交付说明，只能写在对话回复里。
- 判断标准：不看本次对话，只看注释，能否把它理解成当前代码需要长期维持的业务事实；如果只能理解成“这次为什么这么改”，就必须删除，或改写成不包含改动过程的业务事实。
- 字段归并、函数抽取、Options 复用等代码结构变化，禁止再用注释复述改动过程。代码能看出来的，注释不要再讲一遍。
- **正式注释与临时预留说明必须分离**：JSDoc、字段说明、函数说明、模板业务注释等正式注释只说明稳定业务含义，例如“业务字段”“操作入口”“数据结构”。待联调原因、后端缺口、临时值来源、联调时删除 / 替换范围等临时说明，必须放在 `@todo-start` / `@mock-start` 标记行、独立 TODO 字段名或最终交付说明中。禁止把 `TODO待联调_` / `TODO无此联调字段_`、“最终以后端为准”、“待后端确认”等内容混进正式 JSDoc，导致联调时还要判断正式注释是否需要修改。
- 注释应写业务事实，例如接口字段来源、业务分支含义、特殊兜底原因。

```ts
// ❌ 禁止 - 向用户交代本次字段收口
/** 已确认业务类型统一使用详情字段 xxx */

// ✅ 正确 - 只说明长期业务事实
/** 详情 xxx，来自接口字段 xxx */
```

```ts
// ❌ 禁止 - 共用同一结果时，注释写成改动说明
// 人工处理、自动处理、定时处理（mode = 1、2、3）：统一使用同一接口字段。

// ✅ 正确 - 共用同一结果时，只写业务结果
// 人工处理、自动处理、定时处理（mode = 1、2、3）：展示业务字段。
```

示例：

```javascript
/** 绑定赠送金额 */
giftAmount: ''

/** 获取绑定赠送金额 */
async fetchGiftAmount() {
    // 先校验参数
    if (!this.userId) return

    /** 接口响应数据 */
    const res = await api.getGiftAmount()
    this.giftAmount = res.data
}
```

```javascript
// ❌ 禁止 - 把规则提醒写进业务代码
// 使用 code 判断，禁止用 name 文案做业务判断
return optionItem.value === TARGET_SCENE_CODE

// ✅ 正确 - 只说明当前业务事实
// 目标场景：接口 code = TARGET_SCENE_CODE
return optionItem.value === TARGET_SCENE_CODE
```

# 文件头部注释规范

**核心原则**：所有代码文件顶部需添加功能描述注释，说明该文件是哪个页面或功能。

**格式要求**：

| 文件类型   | 注释格式            | 示例                         |
| ---------- | ------------------- | ---------------------------- |
| .vue       | `<!-- 功能描述 -->` | `<!-- 提现/充值抽屉组件 -->` |
| .js/.ts    | `/** 功能描述 */`   | `/** 公共接口定义 */`        |
| .jsx/.tsx  | `/** 功能描述 */`   | `/** 用户列表页面 */`        |
| .scss/.css | `/* 功能描述 */`    | `/* 全局公共样式 */`         |

**注意事项**：

- 注释放在文件最顶部（第一行）
- 描述应简洁明了，说明文件的用途或所属功能模块
- 不要放文件路径，而是描述功能
