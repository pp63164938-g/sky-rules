# 严格模式工作流

> [!CAUTION]
> 本工作流要求严格遵守全局规则（`~/.gemini/GEMINI.md`）中的所有规范，任何偏差都需要先与用户确认。

## 执行前

1. **必须先阅读全局规则**：使用 `view_file` 查看 `~/.gemini/GEMINI.md`，逐条理解所有规范
2. **对照规则逐项检查**：每次生成代码前，对照全局规则中的各项规范进行自检

## 执行原则

1. **不确定就问**：遇到规则未覆盖的情况，先询问用户
2. **禁止自行发散**：字段、翻译、逻辑都不能自己编造
3. **标记待办**：使用 `TODO` 前缀标记所有待确认项
4. **及时沟通**：发现问题立即反馈，不隐藏

## 终端命令执行策略

> [!CAUTION]
> **禁止使用 `run_command` 工具！** 所有终端命令都由用户手动执行。

### 执行流程

1. 列出需要执行的命令（带编号）
2. 说明每条命令的作用
3. 等待用户反馈执行结果
4. 根据结果继续下一步
