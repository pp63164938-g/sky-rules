# i18n 翻译工作流

## 两种模式

### 模式一：梳理模式（用户未提供翻译）

当用户未提供翻译内容时，梳理出待翻译的字段，以表格形式呈现：

```markdown
## 待翻译字段

| 中文文件现值 | 英文文件现值 | 备注 | 已有精准翻译 |
|-------------|-------------|------|------------|
| 提现设置 | TODO翻译_提现设置 | - | - |
| 请输入{amount}金额 | TODO翻译_请输入{amount}金额 | 使用变量插值 | - |
| 正确邮箱 | TODO翻译_正确邮箱 | 需特殊样式 | - |
```

**梳理规则**：
- **已有精准翻译**：必须是项目中已存在的完全匹配的翻译，禁止模糊推断。
- **变量插值**：使用 `{变量名}` 方式，并在备注中说明。
- **连贯翻译**：若文本中包含特殊样式，应在备注中说明需连贯翻译，并在表格后说明拆分逻辑。
- **一键复制**：在表格最后提供**纯文本形式的中文列表**，方便用户批量翻译。

### 模式二：替换模式（用户提供翻译）

当用户提供翻译内容时，直接替换 i18n 文件中的对应值。

**执行步骤**：
1. 按用户提供的内容替换 i18n 文件
2. 检查是否有缺失、不够、不明确的字段
3. 如有问题，**及时提出**，列出具体问题

## 特殊情况处理

### 变量插值

使用 `{变量名}` 方式插入动态内容：

```javascript
// 中文
pleaseEnterAmount: '请输入{amount}金额'
// 英文
pleaseEnterAmount: 'Please enter {amount} amount'
```

### 半路插入样式

当一段文本中有部分需要特殊样式时：

```javascript
// 拆分为多个 key，便于样式控制
emailTip: {
  prefix: '该邮箱用于接收提现验证信息，请务必填写您常用的',
  highlight: '正确邮箱',  // 需要特殊样式的部分
  suffix: '地址'
}
```

**备注格式**：`连贯翻译，"xxx"需特殊样式`

## 检查清单

- [ ] 所有 `TODO翻译_` 已替换为正式翻译
- [ ] 变量插值语法正确（`{变量名}`）
- [ ] 特殊样式部分已正确拆分
- [ ] 中英文文件结构一致

## 一键复制

梳理完成后，在表格末尾提供**纯文本格式的中文列表**，要求如下：

1. **按模块分组**：将文本按照页面或功能模块进行分组。
2. **格式规范**：
   - 每个模块顶部使用斜体文字作为标题（例如：`*首页模块*`）。
   - **模块内**：每个词条占用一行，仅使用换行符，不留空行。
   - **模块间**：使用空行分隔不同模块。
3. **内容完整**：
   - 包含所有待翻译文本。
   - 带有插值变量的文本（如 `{day}`）保持原样输出。
   - 连贯翻译的文本（即使样式需拆分）在此列表中应合并为完整句子。

```markdown
## 待翻译文本（复制后翻译）

*首页模块*
前往签署
审核中

*提现记录*
提现时间
到账金额
提现状态
```
