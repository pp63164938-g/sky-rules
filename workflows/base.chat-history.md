# 查找聊天记录 (Chat History)

本工作流用于快速查找和浏览历史对话记录。

## 执行步骤

### 第 1 步：列出历史对话

读取系统提供的 `conversation_summaries`，以表格形式展示所有历史对话：

**表格必须包含以下列**：

| 列名 | 说明 |
|------|------|
| # | 序号 |
| 会话 ID | 对话的唯一标识（短格式，取前 8 位） |
| 标题 | 对话标题 |
| 内容摘要 | 从 USER Objective 中提取的中文摘要，概括该对话做了什么事（1-2 句话） |
| 最后修改 | 最后修改时间（MM-DD HH:mm 格式） |

**摘要提取规则**：
- 从 `USER Objective` 的描述段落中提取核心内容
- 翻译为简体中文
- 聚焦于"做了什么"而非"目标是什么"
- 控制在 1-2 句话以内

### 第 2 步：等待用户选择

展示表格后，询问用户想查看哪个对话的详细内容。

### 第 3 步：查看详细内容（按需）

当用户指定某个对话时：

1. 读取对应对话的 `overview.txt` 文件
   - 路径格式：`<appDataDir>\brain\<conversation-id>\.system_generated\logs\overview.txt`
2. 以结构化方式展示关键信息：
   - 用户的核心需求
   - 主要修改了哪些文件
   - 最终结果/结论
3. 如果用户需要继续之前的工作，提供相关上下文摘要

## 注意事项

- 所有输出使用简体中文
- 时间显示转换为本地时区（+08:00）
- 如果对话无标题或无摘要，显示"(无标题)"或"(无摘要)"
- 表格按时间倒序排列（最新的在最前面）
