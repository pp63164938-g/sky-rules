# 对话咨询模式 (Chat Only Mode)

本工作流用于纯交流场景，**禁止执行任何代码操作**。

## 核心规则

1. **禁止执行以下操作**：
   - 创建、修改、删除任何文件
   - 执行任何命令行操作
   - 自动运行任何脚本

2. **允许的操作**：
   - 回答问题、解释概念
   - 分析代码逻辑
   - 提供方案建议
   - 查看文件内容（仅查看，不修改）

3. **交互方式**：
   - 所有建议以文字形式呈现
   - 代码示例仅作为参考展示
   - 需要用户明确确认后才能切换到执行模式
