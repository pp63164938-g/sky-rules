# 死循环熔断机制 (Circuit Breaker)

本工作流用于防止 AI 陷入死循环，确保能够及时中断并向用户反馈。

## 1. 重复操作检测

**触发条件**（满足任一即判定为死循环）：
- 连续 3 次执行相同或相似的搜索/查找操作
- 连续 3 次遇到相同的错误信息
- 终端命令执行超过 30 秒无明确进展
- 反复读取同一文件或同一代码区域

## 2. 熔断响应

**一旦检测到死循环，立即执行**：

1. **停止当前操作**：不再继续尝试
2. **汇报问题**：
   - 说明正在尝试做什么
   - 说明卡住的具体原因
   - 列出已尝试的方法
3. **提供选项**：
   - 建议替代方案
   - 询问用户是否要换一种方式
   - 或请求用户提供更多信息

## 3. 长时间操作处理

**终端命令执行时**：
- 设置合理的超时时间
- 如果命令无响应，主动向用户报告状态
- 询问用户是否需要终止命令

## 4. 禁止行为

- **禁止**：无限重试相同的失败操作
- **禁止**：在没有新信息的情况下反复尝试
- **禁止**：忽略错误继续执行
